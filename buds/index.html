Classic Bluetooth serial. Works in Chrome or Edge on Windows, macOS and ChromeOS after the buds are paired in system settings. Not available on iPhone.

Where to run it

  • iPhone: open this page in the Bluefy app. Safari and Chrome on iPhone can't use Bluetooth.
  • Windows: Chrome or Edge. Pair the buds in Settings → Bluetooth & devices to use the SPP tab.
  • Android: Chrome.

Capture on iPhone + Mac

  1. Install Apple's Bluetooth logging profile on the iPhone (developer.apple.com/bug-reporting/profiles-and-logs) and restart.
  2. On the Mac, open PacketLogger from Additional Tools for Xcode → File → New iOS Trace, with the iPhone plugged in.
  3. In realme Link tap ANC → Transparency → Off, about 10 s apart, then repeat once.
  4. Save the .pklg, copy it to this device, and load it in Import capture.

Capture on Android

  1. Developer options → Enable Bluetooth HCI snoop log → Enabled, then toggle Bluetooth.
  2. Do the same tap sequence in realme Link.
  3. Developer options → Take bug report. In the zip, find btsnoop_hci.log.

Windows can't record the phone's traffic, but it can open the capture file here and run the controls.
